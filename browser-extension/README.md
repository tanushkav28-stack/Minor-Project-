# Cognivibe AI - Browser Extension (Component A)

This Chrome / Microsoft Edge extension integrates directly into social media platforms (Reddit, Twitter/X, Instagram, YouTube) to screen user-authorized text and code-mixed Hinglish posts for mental health and emotional language indicators.

## Features
- **Selected Text Analysis**: Select any text on any webpage to see a floating "🧠 Analyze with Cognivibe" trigger.
- **Platform Adapters**: Automatically injects "🧠 Analyze Post" buttons on Reddit posts/comments, Twitter/X tweets, Instagram captions, and YouTube comments.
- **Context-Aware Analysis**: Trajectory tracking across multiple turns.
- **Multitask Predictions**: Emotion (7 categories) and Depression-Related Language (5 indicators + none).
- **Crisis Intervention**: One-click confidential helplines (Tele-MANAS, KIRAN).
- **Pairing with Web App**: Enter your `extension_token` in the extension popup settings to sync analyses to your dashboard history.

## How to Install in Google Chrome or Microsoft Edge
1. Open Google Chrome and navigate to `chrome://extensions/` (or `edge://extensions/` in Edge).
2. Toggle on **Developer mode** in the top-right corner.
3. Click **Load unpacked**.
4. Select the `browser-extension` folder inside this project directory (`Mental health project minor/browser-extension`).
5. The **Cognivibe AI** extension icon will appear in your browser extension bar!
